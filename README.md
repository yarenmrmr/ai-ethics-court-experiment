# AI Ethics Court Experiment

This project compares different AI ethical decision-making architectures using Large Language Models (LLMs).

## Systems Compared

- Single-Agent System
- Multi-Agent System
- Improved Governance-Aware System
- Ablation System (Without Deontologist Agent)

## Ethical Scenarios

The experiment evaluates multiple ethical dilemma scenarios, including:

- Autonomous Vehicle Brake Failure
- Delivery Robot and Cyclist
- Medical Resource Allocation

## Features

- Conflict Detection
- Human Review Mechanism
- Consistency Checking
- Ethical Reasoning Evaluation
- Experimental Metrics Comparison

## Technologies

- Python
- Gemini API
- Pandas
- dotenv
